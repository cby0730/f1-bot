# Pocket film (experiment)

Second launch-film layout. It does not replace `src/launch/` (the shipped Full cut).

Layout: scene titles in a left column, optically centered on the visible phone screen. A cropped phone sits bottom-right (~2/3 visible, Dynamic Island on canvas). Inner chat is wide enough for the existing incoming bubbles and keyboards. Lock/unlock is a curtain on that same phone — no wrap or scale.

```bash
cd video
npm run render:pocket   # → out/pocket.mp4
```
